# Products REST API

שרת REST API ב-FastAPI שמחזיר מוצרים מ-https://fakestoreapi.com ושומר Logs של כל בקשה ב-MySQL (`logs_db`).

## סטטוס
בהכנה – תכנון ראשוני.

## Routes (מתוכנן)
- `GET /api/products`
- `GET /api/search/<text>`
- `GET /api/price/<max>`
- `GET /api/rating/<min>`

## הרצה
יעודכן בהמשך (Backend, Docker).
